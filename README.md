# Auracle Homebrew tap

Official Homebrew packages published from signed Auracle releases.

Install the macOS app:

```sh
brew install --cask auracarehq/tap/auracle
```

The cask installs the notarized `Auracle.app` from the corresponding GitHub
Release. Auracle's separately distributed GPLv3 iMessage exporter is never
bundled into the app or its cask.
